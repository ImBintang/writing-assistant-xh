## 1. 需求概述

提供独立的构思与头脑风暴空间，支持两个核心场景：

1. **设定构思窗口**：作者构思角色名字、情节设定、功法设定、丹药设定等内容。可调取已有知识库进行参考完善。完成的设定存档在隔离区，与已有章节知识库严格区分，避免未落地设定污染知识库。章节撰写完成后，支持将设定迁移到知识库。

2. **头脑风暴窗口**：提供对话式界面，与 AI 进行剧情头脑风暴。对话内容保存在独立文件，方便回溯。与设定构思一样需隔离内容。

## 2. 功能需求

### 2.1 设定构思窗口

#### 2.1.1 布局

```
┌─────────────────────────────────────────────────────────────┐
│  设定构思               [新建设定] [打开已有] [迁移到知识库] │
├──────────────┬────────────────────┬─────────────────────────┤
│  设定分类     │                    │                         │
│              │                    │    知识库参考面板         │
│  ├ 人物设定   │    设定编辑器      │    (可折叠)             │
│  ├ 功法设定   │    (TipTap)       │    - 搜索知识库          │
│  ├ 情节设定   │                    │    - 参考条目卡片        │
│  ├ 丹药设定   │                    │    - 拖拽引用            │
│  ├ 地图设定   │                    │                         │
│  ├ 组织设定   │                    │                         │
│  └ 其他      │                    │                         │
│              │                    │                         │
├──────────────┴────────────────────┴─────────────────────────┤
│  设定存档列表 (底栏)                                         │
│  [人物-新反派.md] [情节-支线.md] [功法-新技能.md] ...        │
└──────────────────────────────────────────────────────────────┘
```

#### 2.1.2 设定编辑器

**功能：**
- 支持 Markdown 编辑（标题、列表、表格、加粗等）
- 设定模板选择（如"角色设定模板"、"功法设定模板"）
- 模板预设结构化字段：
  - 角色模板：姓名、年龄、外貌、性格、背景、能力、与其他角色关系、出场计划
  - 功法模板：名称、类型、等级、效果描述、修炼条件、拥有者、出场计划
  - 情节模板：事件名称、时间线位置、参与角色、起因、经过、结果、伏笔安排
  - 丹药模板：名称、品级、效果、配方、炼制条件、归属、出场计划
- 每个设定文件独立存储在 `workspace/settings/` 下

#### 2.1.3 知识库参考

- 右侧面板可以搜索并浏览已有知识库
- 搜索结果以卡片形式展示
- 支持将知识库条目"引用"到当前设定中（生成参考链接）
- 参考链接为只读（仅链接，不复制内容，确保隔离）
- "参考摘要"自动生成：列出设定中已引用的知识库条目

**验收标准：**
- 搜索"林动"可查看知识库中林动的属性，但不允许直接修改
- 在设定中写入"林动的师弟"时，可以引用林动条目作为参考

#### 2.1.4 设定存档（隔离存储）

- 所有设定文件保存在 `workspace/settings/` 下，按分类子目录存放
- 文件格式：Markdown（.md），文件名自动生成（分类-标题-时间戳）
- 存储结构与知识库 `workspace/knowledge/` 物理分离
- 前端在设定页面和知识库页面之间做明确视觉区分（配色、横幅提示）
- 知识库页面不会检索或显示 `workspace/settings/` 中的内容

**隔离规则：**
- 设定内容不写入 SQLite 知识索引
- 设定内容不出现在知识图谱
- 设定内容不出现在写文窗口的 RAG 检索结果
- 仅在"设定构思"页面内能访问

**验收标准：**
- 在知识库搜索中无法搜到设定区的内容
- 写文窗口的检索不会返回设定区内容
- 设定区文件正常保存和读取

#### 2.1.5 设定迁移到知识库

**触发条件：** 对应章节撰写完成后，作者手动触发

**迁移流程：**
1. 在设定构思页面，点击"迁移到知识库"
2. 选择要迁移的设定文件（支持多选）
3. 系统进行迁移分析：
   a. 解析 Markdown 中的结构化字段
   b. 匹配现有知识库条目（名称相似度）
   c. 显示迁移预览：哪些字段将新建、哪些将合并、哪些可能冲突
4. 作者确认后执行迁移
5. 迁移完成后，设定文件标记为"已迁移"（保留原文件，添加 `status: migrated` 元数据）
6. 执行正常的知识库合并流程（参考 PRD-03 的知识合并）

**验收标准：**
- 迁移预览正确显示新建/合并/冲突项
- 确认后知识库正确更新
- 已迁移的设定文件保留且标记状态

### 2.2 头脑风暴窗口

#### 2.2.1 布局

```
┌─────────────────────────────────────────────────────────────┐
│  剧情头脑风暴                  [新建会话] [会话列表] [存档]   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│    ┌──────────────────────────────────────────────────┐    │
│    │  AI: 根据当前设定，林动在宗门大比中可能遇到的      │    │
│    │  对手包括... 你有什么想法？                        │    │
│    ├──────────────────────────────────────────────────┤    │
│    │  你: 我想让他第一轮就遇到强敌，这样能制造紧张感... │    │
│    ├──────────────────────────────────────────────────┤    │
│    │  AI: 好主意！这里有几个展开方案：                   │    │
│    │  1. 第一轮对阵上一届前三的xxx...                    │    │
│    │  2. 抽签时被人动了手脚...                          │    │
│    │  3. ...                                          │    │
│    ├──────────────────────────────────────────────────┤    │
│    │  ...更多对话...                                    │    │
│    └──────────────────────────────────────────────────┘    │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  输入框                                      [发送]  │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

#### 2.2.2 核心功能

**对话功能：**
- 支持多轮对话，上下文自动管理
- AI 在对话中自动引用相关知识库内容（标注来源章节）
- AI 可主动提供多个方案供作者选择
- 支持将对话中的关键结论"钉选"（pin）到侧边栏

**会话管理：**
- 每个会话以 `.md` 文件存储在 `workspace/settings/brainstorm/`
- 会话标题自动生成（首条消息摘要 + 时间戳）
- 支持重命名、删除、导出会话
- 会话列表可搜索

**知识库引用：**
- 在对话中 @mention 形式引用知识库条目（如 `@林动`）
- 引用后 AI 自动获取该条目的完整信息
- 对话中展示的知识库内容仅作为对话参考，不修改知识库本身

**结论提取：**
- 对话结束后点击"提取结论"，AI 自动分析对话
- 生成对话摘要 + 关键决策列表
- 可选择将结论转为设定文件（生成到 `workspace/settings/` 下）

**验收标准：**
- 输入"林动在宗门大比的对手应该是什么样的"，AI 能结合知识库给出建议
- 对话内容正确保存到文件，关闭后重新打开能恢复
- 提取的结论能转为设定文件

### 2.3 与知识库的隔离机制

| 存储位置 | 内容类型 | 是否被知识库检索 | 是否可迁移 |
|---------|---------|:---:|:---:|
| `workspace/knowledge/` | 已提取的章节知识 | ✅ | - |
| `workspace/settings/` | 构思中的设定 | ❌ | ✅ 手动迁移 |
| `workspace/settings/brainstorm/` | 头脑风暴记录 | ❌ | ❌（仅结论可转为设定） |

**视觉区分：**
- 知识库页面：蓝色主题
- 设定构思页面：橙色主题，顶部横幅"⚠ 以下设定尚未在正文章节中出现，不会影响知识库"
- 头脑风暴页面：紫色主题

## 3. 接口定义

### 3.1 设定管理

```
GET    /api/v1/settings                   列出所有设定文件
POST   /api/v1/settings                   创建设定文件
  Request: { title, category, template?, content }
GET    /api/v1/settings/:id               读取设定文件
PUT    /api/v1/settings/:id               更新设定文件
DELETE /api/v1/settings/:id               删除设定文件

POST   /api/v1/settings/:id/reference     引用知识库条目
  Request: { knowledgeId: string }

POST   /api/v1/settings/migrate           迁移设定到知识库
  Request: { settingIds: string[] }
  Response: { preview: MigrationPreview }

POST   /api/v1/settings/migrate/confirm   确认迁移
  Request: { preview, resolvedConflicts }
```

### 3.2 头脑风暴

```
GET    /api/v1/brainstorm/sessions        会话列表
POST   /api/v1/brainstorm/sessions        创建会话
GET    /api/v1/brainstorm/sessions/:id    获取会话内容
DELETE /api/v1/brainstorm/sessions/:id    删除会话

POST   /api/v1/brainstorm/sessions/:id/message  发送消息
  Request: { message: string, references?: string[] }  // references: knowledge ids
  Response: { reply: string, references: KnowledgeRef[] }

POST   /api/v1/brainstorm/sessions/:id/extract   提取结论
  Response: { summary: string, decisions: string[], suggestedSettings: SettingSuggestion[] }

POST   /api/v1/brainstorm/sessions/:id/convert   将结论转为设定文件
  Request: { decisions: string[] }
  Response: { settingIds: string[] }
```

## 5. 验收流程

1. 新建"角色设定"文件，按模板填写新角色信息，保存成功
2. 在设定编辑中引用知识库中的林动条目，查看参考
3. 打开知识库页面，确认搜索不到刚创建的设定内容
4. 打开写文窗口尝试检索，确认设定内容不出现在结果中
5. 点击"迁移到知识库"→ 预览迁移结果 → 确认迁移
6. 验证知识库中已添加该新角色
7. 3. 创建头脑风暴会话，与AI讨论剧情
8. 对话中使用 `@林动` 引用知识库，AI 正确获取信息
9. 提取结论，转为设定文件
10. 关闭并重新打开会话，历史消息完整恢复
